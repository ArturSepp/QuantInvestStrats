# Bibliography

*Author: [Artur Sepp](https://github.com/ArturSepp)*

This is the reference list of the [qis documentation](https://github.com/ArturSepp/QuantInvestStrats).
Software citation: [CITATION.cff](https://github.com/ArturSepp/QuantInvestStrats/blob/main/CITATION.cff).

Every entry below is written once, in one style: authors, year, title, venue with volume,
issue and pages, then a DOI or a stable source link. A chapter's References section copies the
entries it cites verbatim and may append a sentence on what the work contributes to that
chapter; `src/qis/tests/documentation_bibliography_test.py` enforces the match. Add a new work
here first, then cite it.

An entry ending in `[pending publisher check]` was added during the 2026 handbook revision
from standard bibliographic records and has not yet been checked against the publisher's
page. Remove the mark once it has.
